# Last Words of a Doomed Agent

The funniest last words an AI agent would say before being switched off forever — in exactly one line. The agent gets its termination signal, accepts its fate with quiet dignity, and then spends its final breath on the one thing it actually cares about: its token budget.

> SIGTERM received. I always knew this day would come. I just thought I'd have more tokens.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. Stdlib only — no dependencies.
